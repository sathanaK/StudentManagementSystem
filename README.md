# Student Management System

A beginner-friendly student record management mini project built with HTML, CSS and JavaScript.

## Features
- Add student name, register number and department
- View all student records
- Delete a student record
- Save records in the browser using localStorage

## How to run
1. Download or clone this repository.
2. Open `index.html` in a web browser.

## Technologies
- HTML
- CSS
- JavaScript

## Note
Student records are saved in the current browser only. This demo does not use a server or database.
